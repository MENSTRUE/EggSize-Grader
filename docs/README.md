## Source-of-truth hierarchy
1. Original experiment reports (`../reports/`), not text copied elsewhere.
2. Executable notebook (`../notebooks/eggsizegrader.ipynb`) for methodology.
3. Actual backend/frontend implementation (`../backend/app/`, `../frontend/src/`) for endpoints and UI.
4. Visuals (`../assets/`) for illustrative evidence.
5. This prose, which may lag changes and must be updated when code or experiment changes.

Read [English evaluation](en/evaluation.md) or [evaluasi Indonesia](id/evaluation.md) for the exact validation/test distinction. No documentation creates a released `.pt` binary or production deployment claim. See [research limitations](en/limitations.md), [batasan riset](id/limitations.md), and component READMEs.
